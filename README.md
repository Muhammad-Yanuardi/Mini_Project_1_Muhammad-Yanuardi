# Sistem Pendataan Koleksi Board Game Pribadi

Dokumentasi tugas Mini_Project_1 DDP Praktikum untuk mengelola data koleksi board game menggunakan Python.


## Deskripsi Program/Penjelasan Program
Program Python sederhana untuk kelola koleksi board game (CRUD). Data awalnya disimpan di Tuple, lalu dipindah ke List supaya bisa ditambah, dilihat, diubah, dan dihapus lewat menu interaktif yang jalan berulang (while True).
